# Lizenz der Datendateien

Die JSON-Dateien in diesem Ordner sind abgeleitete Auswertungsergebnisse des
Feldbuchs ([geophora.de/blog/](https://www.geophora.de/blog/)). Soweit unten nicht
anders vermerkt, stehen sie unter
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.de) —
Namensnennung: „Robert Rettig, Feldbuch (geophora.de/blog/)".

Jede Datei nennt im Feld `"aufruf"` den wörtlichen Skriptaufruf, der sie erzeugt
hat; die Skripte liegen in diesem Repository.

## Herkunftsvermerke je Quelle

- **Sentinel-2-Ableitungen** (`trend-*.json`, `fundstellen-*.json`,
  `skalenprobe-*.json`, `duerre-ammerland-2026-W33.json`, `saisonprobe-botswana.json`,
  `punktauswertung-botswana.json`, `punkttrend-botswana.json`):
  *Contains modified Copernicus Sentinel data [Jahre laut Datei]* — bezogen über das
  Copernicus Data Space Ecosystem.
- **DWD-Ableitungen** (`klima-ammerland-1991-2025.json`): Datenbasis Deutscher
  Wetterdienst, eigene Elemente ergänzt.
- **OSM-Ableitungen** (`duerre-ammerland-stichprobe.json`, enthält aus OpenStreetMap
  abgeleitete Standorte): © OpenStreetMap contributors, Lizenz
  [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) — diese Datei steht
  abweichend unter ODbL.
